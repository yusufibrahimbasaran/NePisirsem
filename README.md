# 🍳 Ne Pişirsem? - Akıllı Dolap & Mutfak Asistanı

> Evdeki malzemelerle "Bugün ne pişirsem?" derdine son veren, ev hanımları ve öğrenciler için tasarlanmış modern, sade ve pratik yemek asistanı.

---

## ✨ Özellikler

- 🧊 **Akıllı Dolap & Kiler:** Dolabınızdaki malzemeleri tek dokunuşla seçin; elinizdekilerle hemen pişirilebilecek yemekleri listeleyin.
- 🎯 **Akıllı Eşleşme Oranı:**
  - 🟢 **Tüm Malzemeler Var:** Dolaptakilerle %100 hemen yapılabilir.
  - 🟡 **1-2 Eksik Malzeme:** Eksik malzemeyi gösterip tek tıkla pazar listesine ekler.
- 🎡 **Günün Şanslı Yemeği (Ne Pişirsem Çarkı):** Kararsız kaldığınız günlerde çarkı çevirerek menünüzü belirleyin.
- 👩‍🍳 **Sihirli Menü Önerisi:** Kalan malzemeleri israf etmeden birleştiren lezzetli mutfak tavsiyeleri.
- 🛒 **Pazar & Market Listesi:** Eksik kalanları tek tıkla WhatsApp / SMS formatında paylaşın.
- 👤 **Kullanıcı & Profil Yönetimi:** Ev hanımı veya öğrenci profilleri arasında geçiş yapın, dolabınızı ve favorilerinizi kaydedin.
- 📱 **Mobil & Web Uyumlu:** PWA destekli, telefon ve bilgisayarda kusursuz çalışan sade ve sıcak arayüz.

---

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirme sunucusunu başlatın
npm run dev

# 3. Canlı üretim derlemesi (Build)
npm run build
```

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** React 19, Vite
- **Stil & Tasarım:** Vanilla CSS (Warm Terracotta & Olive Culinary Theme)
- **İkonlar:** Lucide React
- **Animasyon:** Canvas Confetti
- **Veri Saklama:** LocalStorage tabanlı kullanıcı izolasyonu
